# elyos-cli

A command-line chat app that streams LLM responses in real time, with tool calling against a weather API and a research API.

## Setup

```bash
pnpm install
```

Copy `.env.example` to `.env` and fill in the values

```bash
cp .env.example .env
```

## Run

```bash
pnpm start
```

Type a message at the `You:` prompt.
